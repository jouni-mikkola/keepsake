# Third party code

Keepsake ships unchanged copies of these libraries in `src/vendor`.

[mux.js](https://github.com/videojs/mux.js) 6.3.0, Apache License 2.0

[DOMPurify](https://github.com/cure53/DOMPurify) 3.4.18, Apache License 2.0 or MPL 2.0

[Readability](https://github.com/mozilla/readability) 0.6.0, Apache License 2.0

To update them run `npm install` and then `npm run vendor`.
